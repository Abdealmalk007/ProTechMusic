## Scope and functionality
- Added persistent Media3 playback queue actions: play-next, enqueue, move-up/move-down, remove-from-queue without deleting original audio, jump-to-queue-entry, queue-view in scrollable filter chips.
- Queue persisted in existing SharedPreferences JSON and restored after app UI close/reopen (verified with two tracks).
- Added bounded UTF-8 M3U8 parser and exporter, EXTINF/title/artist support, BOM and percent-decoded legacy filenames.
- URI match uses exact content URI first, falls back only to unique title/artist matches; missing and ambiguous track names reported, never guesses on duplicates. Neither imports nor exports audio payloads.
- SAF OpenDocument and CreateDocument integration. Import creates an editable local playlist; export writes a .m3u8 UTF-8 file.
- List and playlist title configured for one-line truncation at large system font.
