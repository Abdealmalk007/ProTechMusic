## Code changes
1. Bottom navigation now uses Compose WindowInsets.navigationBars via windowInsetsPadding.
2. NavigationBar consumes zero extra insets to avoid double padding; app adds extra 8dp clearance before system navigation bar.
3. Five navigation labels are one line with 11sp font and ellipsis; icons 20sp, 5 destinations preserved.
4. Mini-player always remains compact in bottomBar. Expanded now-playing is a ModalBottomSheet with bottom navigation inset padding rather than consuming music library viewport.
5. Track rows minimum 72dp; play/add/more click surfaces at least 48dp; favorite/share/reorder/remove grouped in accessible overflow menu, while add-to-playlist remains direct.
6. Playlist title constrains to available width; selection bulk action row is horizontally scrollable on narrow phones.
7. Expanded player actions scroll horizontally on small widths; ModalBottomSheet and PlayerBar explicitly set white content color, fixing black text on dark background.
