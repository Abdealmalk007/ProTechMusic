## Implemented
- ExoPlayer automatic next-track playback in current queue, repeat one/all/off UI as previously implemented, now explicit remembered state at end.
- Explicit play selected playlist only, in persisted ordered mode or random shuffle mode. Shuffle stored in SharedPreferences and restored.
- Single, arbitrary multiple, or select all visible tracks with bulk add-to-playlist, sharing (Android Sharesheet), ordered/shuffle playback, permanent deletion.
- Two distinct semantics: remove a track from app playlist only (retains original audio) vs delete from device permanently.
- Two user-consent gates for permanent deletion: app confirmation with file count and irreversible warning, then Android platform delete-request system consent. Android 11+ via MediaStore.createDeleteRequest in 150-URI batches; Android 10 RecoverableSecurityException; Android 8/9 scoped WRITE_EXTERNAL_STORAGE runtime permission. Only numeric MediaStore audio item content://media URIs accepted; SAF-only or private app data are excluded.
- Upon successful delete, corresponding DB playlist/favorite/import references and queued playback references are cleaned; library refreshes.
- Kotlin files: MediaDeletionController.kt, MainActivity.kt, MusicService.kt, MusicStore.kt; AndroidManifest.xml; app/build.gradle.kts versionCode 7 versionName 0.3.4.
- Lower safe navigation inset and 48dp track action targets remain intact from v0.3.2.
